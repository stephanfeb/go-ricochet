# Backlog

The open findings from the [2026-09-13 release audit](audit-2026-09-13/README.md)
that sat below its blocker line, plus anything found since. The eleven
blockers are done (see the status note at the top of the audit). This file
is the working list: one item at a time, one commit per item, the full
suite on a fresh database after each, the row updated in the same commit.

**How to use this file.** Pick the next `open` item, verify its anchors
(line numbers drift), fix it, add the test that would have caught it, mark
the row `done <date>` naming the test, in the same commit as the fix
(`git log -S<test name>` finds it). When an item is deliberately not going
to be fixed, mark it `wontfix` with one line of reasoning so it is not
re-investigated. Anchors are `file:line` as of the commit that last edited
this file.

Suggested order: the four correctness bugs a user can hit today (P5, P4,
P3, S1), then the one security item with no workaround (S2), then the rest
by section.

| S4 | done 2026-09-13 | **Directory search was an unbounded, unescaped `ILIKE`.** `internal/storage/postgres/postgres.go:919` builds `coalesce(display_name,'') ILIKE $n OR coalesce(bio,'') ILIKE $n` with `%q%`; `%` and `_` in the query are wildcards, there is no length cap, and the FTS index is unused. | S5 | done 2026-09-13 | **Every per-peer limit is keyed by a free identity.** Rate limits, admission per-peer caps, mailbox quotas and forwarding trust are all per peer ID, which costs nothing to mint. Audit A M-7. |

| S8 | done 2026-09-13 | **Encryption had no forward secrecy and was not bound to the envelope.** `pkg/client/encryption.go` NaCl box with static X25519 keys derived from the identity; ciphertext is not bound to sender/recipient/folder, so a captured ciphertext can be replayed into another folder. | N6 | open | **Documents, feeds and collections have no read authorization.** S7 documented that any peer can read every document, feed and collection; the handlers check ownership on writes only (`internal/protocol/sda/handler.go:281-286`, `sca/handler.go:171`, SFA the same) and the `documents`, `feeds` and `collections` tables in `schema.sql` have no visibility column.
